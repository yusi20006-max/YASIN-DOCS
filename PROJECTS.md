# Yasin Projects

This document is the entry point for the Yasin project registry.

## Registry Status

The registry will be populated and verified during **Phase 2 — Repository Discovery**. Project roles listed before that audit are provisional and must not be treated as authoritative implementation facts.

## Known Ecosystem Projects

The current documentation effort is expected to cover, at minimum, the following projects and tools referenced in the Yasin ecosystem:

- Yasin-Core
- Yasin-Agent
- Yasin-AI
- YasinHub
- YasinRelay
- YasinFeed
- YasinPress
- Yasinnews
- YasinCLI
- YasinDocs / YASIN-DOCS
- TJC (Termux Jules CLI)
- Termux Backup Manager

The final registry will record the exact GitHub repository, category, responsibility, status, dependencies, consumers, interfaces, and cross-project impact for each project.

## Required Project Record

Every project record should answer:

1. What is this project?
2. What problem does it solve?
3. What are its responsibilities?
4. What is explicitly outside its responsibility?
5. What does it depend on?
6. What depends on it?
7. What interfaces does it expose?
8. What external systems does it integrate with?
9. What is implemented today?
10. What is planned?
11. What are the known constraints and risks?
12. What changes in another repository could affect it?
