# AI Documentation

This section is specifically designed to make the Yasin Ecosystem understandable and operable by AI coding agents.

## Planned Documents

- `AI_CONTEXT.md` — concise but complete ecosystem context for an AI agent
- `AI_AGENT_GUIDE.md` — how an AI agent should inspect and modify Yasin
- `CODING_AGENT_RULES.md` — mandatory safety and architecture rules
- `PROJECT_HANDOFF.md` — transfer package for continuing work in another AI session
- `ARCHITECTURE_REASONING.md` — rationale behind important architectural boundaries

The AI documentation must distinguish verified repository facts from proposals and must always point agents back to the actual source repository for implementation details.
